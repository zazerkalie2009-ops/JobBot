# 🤖 AI Job Agent: Автономный поиск, адаптация резюме и автоотклики

AI-агент, который мониторит вакансии, оценивает Match Score, адаптирует резюме в формате `.docx` под боли конкретного нанимающего менеджера, пишет адресное сопроводительное письмо и автоматически заполняет формы отклика через Playwright.

---

## 📁 Структура проекта

```
auto_job_agent/
├── master_profile.json      # Единый источник правды: проекты, метрики, навыки Олега Кохтенко
├── bot.py                   # Telegram-бот (интерфейс управления, сканирования и подтверждения)
├── llm_engine.py            # Движок анализа вакансий, скоринга и генерации Cover Letter
├── docx_generator.py        # Генератор резюме в формате DOCX на лету
├── vacancy_parser.py        # Парсер вакансий из Telegram-экспортов, каналов и ссылок
├── browser_applier.py       # Playwright-модуль автоматического заполнения форм и загрузки CV
├── database.py              # SQLite хранилище вакансий, скоринга и статусов откликов
├── config.py                # Загрузка конфигурации
├── .env.example             # Шаблон переменных окружения
└── generated_resumes/       # Папка со сгенерированными DOCX под каждую вакансию
```

## ⚡️ Быстрый старт за 2 минуты

### Шаг 1: Создание бота в Telegram
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Введите имя и юзернейм для бота (например, `OlegJobAgentBot`).
3. Скопируйте полученный **API Token**.

### Шаг 2: Настройка `.env`
В папке `auto_job_agent/` создайте файл `.env` (или скопируйте `.env.example`):
```bash
cp auto_job_agent/.env.example auto_job_agent/.env
```
Откройте `.env` и вставьте ваш токен:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
HEADLESS_BROWSER=False
```

### Шаг 3: Установка браузеров Playwright (однократно)
```bash
playwright install chromium
```

### Шаг 4: Запуск бота
```bash
python3 -m auto_job_agent.bot
```

## 🎮 Как пользоваться ботом

1. **Команда `/start`** — приветствие и проверка связи.
2. **Команда `/scan`** — бот сканирует локальную базу вакансий Яндекса, отбирает топ с Match Score ≥ 80%, генерирует под каждую персонализированный `.docx` и присылает карточки с кнопками.
3. **Отправка ссылки / текста вакансии:**
   * Просто перешлите любой пост из Telegram-канала с вакансией или вставьте ссылку на Яндекс.Вакансии / hh.ru.
   * Бот за 2 секунды посчитает Match Score, подготовит кастомизированный `.docx` и напишет сопроводительное письмо.
4. **Кнопка `[🚀 Откликнуться (Playwright)]`** — запускает браузер, открывает форму вакансии, вводит имя, контакты, сопроводительное письмо и загружает сгенерированный `.docx`.
5. **Кнопка `[📄 Скачать DOCX]`** — бот присылает файл резюме прямо в чат Telegram.
