# Архитектура автономной системы поиска, адаптации резюме и автооткликов

Система автоматизирует цикл от мониторинга вакансий до отправки отклика с кастомизированным резюме (.docx/.pdf) и сопроводительным письмом.

---

## 🏗 Общая схема работы системы (Architecture Overview)

```
[Источники вакансий]
 ├─ Telegram-каналы (TG API / Telethon / Pyrogram)
 ├─ hh.ru (HH API / Parser)
 ├─ Карьерные сайты BigTech (Яндекс, Т-Банк, Авито, Ozon, VK)
 └─ LinkedIn / Habr Карьера
          │
          ▼
 [1. Модуль сбора и фильтрации (Ingestion & Filtering)]
 ├─ Дедупликация вакансий (ID / хэширование)
 ├─ Базовый фильтр: грейд (Middle+/Senior/Lead), локация, стоп-слова
          │
          ▼
 [2. LLM Match & Scoring Engine (Анализ релевантности)]
 ├─ Сравнение требований с Master-профилем кандидата
 ├─ Расчет Match Score (0–100%) и выявление ключевых акцентов
 ├─ Отсечение нерелевантных вакансий (< 70% match)
          │
          ▼
 [3. Генератор кастомизированных материалов (Resume & Cover Letter Generator)]
 ├─ Адаптация формулировок и акцентов под стек вакансии
 ├─ Генерация резюме (.docx + экспорт в .pdf) через python-docx
 ├─ Генерация адресного Cover Letter (3–4 сильных пункта)
          │
          ▼
 [4. Уровень контроля (Human-in-the-loop vs Full-Auto)]
 ├─ Полуавтоматический режим: уведомление в Telegram с кнопками [Откликнуться] / [Пропустить]
 ├─ Автоматический режим: автоотклик при Score >= 85%
          │
          ▼
 [5. Модуль автоотклика (Application Runner)]
 ├─ hh.ru API / Web UI (Playwright / Browser Subagent)
 ├─ Формы на сайтах компаний (заполнение полей + загрузка CV .docx/.pdf)
 ├─ Отправка email / отклик боту в Telegram
          │
          ▼
 [6. CRM & Аналитика воронки (Notion / Google Sheets / SQLite)]
 ├─ Логирование статусов (Отправлено, Просмотрено, Приглашение, Отказ)
 ├─ Аналитика конверсии воронки по типам вакансий
```

## 🧩 Ключевые компоненты системы

### 1. Единый источник правды: Master Profile (`master_profile.json`)
Файл с полным описанием всех ваших проектов, метрик, навыков и вариаций формулировок:
* Все проекты в МегаФоне, Yota, TrueConf с максимальным набором фактов и цифр.
* Матрица компетенций: Gamification, Promo Platforms, AI/Vibe-кодинг, Analytics, B2B/B2C, Delivery.
* Сертификаты, образование, контакты, ссылки на портфолио.

### 2. Модуль мониторинга вакансий (`vacancies_watcher.py`)
* **Telegram:** мониторинг каналов через Telethon (например, @ya_jobs_pm, @product_jobs, чаты с вакансиями).
* **hh.ru:** поиск через официальный API HeadHunter (`/vacancies?text=Product+Manager`).
* **Карьерные сайты:** периодический опрос страниц вакансий Яндекса, Т-Банка, Авито.

### 3. LLM-движок адаптации (`cv_adapter.py`)
* Принимает текст вакансии и `master_profile.json`.
* Выделяет 3–4 ключевые «боли» нанимающего менеджера.
* Переупорядочивает буллеты в резюме, поднимая наверх самые релевантные кейсы.
* Генерирует готовый `.docx` файл и персонализированное сопроводительное письмо.

### 4. Модуль отправки откликов (`auto_applier.py`)
* **Для hh.ru:** прямой вызов API `POST /negotiations` с передачей резюме и письма.
* **Для карьерных сайтов (Яндекс, Авито и др.):** автоматизация браузера через Playwright / Browser Subagent (заполнение имени, телефона, Telegram, загрузка сгенерированного `.docx` или `.pdf`).

### 5. Telegram-интерфейс управления (Бот-ассистент)
* Бот присылает сообщение:
  > 🎯 **Новая вакансия: Яндекс — Платформа промомеханик**  
  > Релевантность: **92%**  
  > 📄 [Сгенерированное резюме.docx]  
  > ✉️ *Сопроводительное письмо:* «...»  
  > [🚀 Откликнуться] [✏️ Изменить] [❌ Пропустить]

## 🛠 План пошагового запуска системы

### Этап 1: Локальный помощник в Antigravity (можно запускать уже сейчас)
* Вы скидываете ссылку на вакансию или текст.
* Агент автоматически генерирует адаптированный `.docx` и сопроводительное письмо.
* Через инструмент `browser_subagent` агент может сам открыть страницу вакансии, заполнить форму и прикрепить резюме под вашим контролем.

### Этап 2: Скрипт пакетного поиска и генерации
* Написание Python-скрипта, который парсит список вакансий из ваших файлов/каналов, отбирает топ-10 лучших и генерирует под каждую персонализированный пакет (CV + Cover Letter).

### Этап 3: Полная автономия (Telegram-бот + Playwright автоотклик)
* Автономный фоновый сервис, который работает 24/7, находит новые вакансии в реальном времени и управляется одной кнопкой в вашем Telegram.
